### 📐 Motion Explorer

An interactive computational calculus laboratory for exploring derivatives, numerical methods, analysis, and integration.

- Custom tokenizer and AST-based parser
- Recursive symbolic differentiation
- Numerical differentiation and floating-point error analysis
- Critical-point, monotonicity, and concavity analysis
- Numerical integration and Riemann sums
- Procedurally generated calculus challenges
- React · TypeScript · Vite

**[Live demo →](https://calculus-motion-explorer-axfuj2ixr-srinidhi-kotteswaran.vercel.app/)** · **[Source →](https://github.com/SrinidhiKotteswaran/calculus-motion-explorer)**

## How I build

I usually start with a question, build a rough version, find where it breaks down, and rebuild from there.

**Question → prototype → test → limitation → rebuild → refine**

Motion Explorer began as a small Python/Streamlit experiment using SymPy, NumPy, and Plotly. I kept the prototype as a record of that process, then rebuilt the project in React and TypeScript with my own symbolic math engine.

**[Original prototype →](https://github.com/SrinidhiKotteswaran/calculus-motion-visualizer)**
